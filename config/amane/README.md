# amane shell

This directory is the amane desktop shell: Rust source, the liquid shader,
the cava visualiser config and the runtime settings. Home-manager symlinks
the whole directory to `~/.config/amane`, which is where the `amane` command
looks by default.

Enable it in `hosts/atlas/home.nix` or `hosts/titan/home.nix`:

```nix
desktop.amane.enable = true;
```

That installs the `amane` command and points `~/.config/amane` here. It does
**not** start anything. To have the shell come up at login:

```nix
desktop.amane = {
  enable = true;
  autostart = true; # opt-in; see "Turning it on" below
};
```

## What came from where

- `src/` — from [suzuha](https://github.com/MystiaFin/suzuha), the author's
  own amane config. Three deliberate changes, listed below.
- `shaders/liquid.wgsl` — from suzuha, unmodified.
- `cava.conf` — from suzuha, unmodified.
- `settings` — written for this desktop. See "Keeping the look".

`Cargo.toml`, `Cargo.lock` and `target/` are generated by `amane compile` and
gitignored. Never edit `Cargo.toml`; it is rewritten on every build and only
lists `amane` as a dependency, so the shell cannot pull in other crates.

## Changes to suzuha

suzuha is written for Niri. amane itself is compositor-agnostic — it binds
`wlr-layer-shell`, and has workspace backends for niri, Hyprland, Sway and
Mango — so the port is three edits, not a rewrite.

### 1. `src/overlay/power_menu.rs` — logout

Upstream runs `niri msg action quit --skip-confirmation`, which is silently
a no-op anywhere else. Now it tries `hyprctl`, then `swaymsg`, then niri.

The other four actions (`systemctl poweroff/reboot/suspend`,
`loginctl lock-session`) were already generic.

### 2. `src/recorder.rs` — focused output

Upstream parsed `niri msg focused-output` for the screen-recording output,
with a note admitting it should use JSON. That command does not exist on
Hyprland, so `wf-recorder` was being invoked with an empty `-o`.

It now asks `hyprctl -j activeworkspace`, falls back to niri's JSON output,
and drops `-o` entirely if neither answers, so wf-recorder records every
output rather than failing.

### 3. `src/theme/scheme.rs` — Catppuccin accent

Upstream's fixed Catppuccin scheme uses Peach (`#ef9f76`) as the accent. The
rest of this desktop is Catppuccin Mocha, whose accent is Blue (`#89b4fa`),
with Lavender (`#b4befe`) on hover. Every other colour already matched Mocha.

## Things that do not work the same on Hyprland

These are upstream limitations, not things that were broken here. They are
left as-is on purpose.

| Feature | Behaviour on Hyprland |
| --- | --- |
| Workspace urgency | amane's Hyprland backend always reports `false` (nixpkgs `#hyprland reports urgent windows, not workspaces`), so the bar's urgent dot stays dark. |
| Wallpaper behind the overview | Cosmetic; niri draws its overview over the wallpaper layer. |
| Rounded screen corners | **Works.** `amane::Mask` is a software alpha cut in the render target, not the layer-shell mask protocol, so it is portable. |
| Notification daemon | Works, but you must stop swaync. amane claims `org.freedesktop.Notifications` and returns quietly if it cannot, so with both running the notifications go to swaync and amane's panel stays empty. |

## Turning it on

amane draws its own bar, its own notification daemon and its own lock
screen. Running it next to waybar, swaync and hyprlock gives you all three
twice. Nothing here deletes anything — each of those is already a module
flag, so you turn them off yourself:

```nix
desktop = {
  amane = {
    enable = true;
    autostart = true;
  };
  # hand these over to the shell
  waybar.enable = false;
  swaync.enable = false;
  swayosd.enable = false;
};
```

`home/amane.nix` emits a warning if you turn on `autostart` while any of
those are still enabled.

Then, in a session:

```sh
amane compile   # first build takes a few minutes
amane run
```

`amane dev` rebuilds and restarts on every save while you edit. Only one
shell can run at a time.

Two things stay regardless of the flags above:

- **Hyprlock still runs.** `config/hypr/hypridle.conf` starts it on idle and
  on lid close. amane's own lock screen listens on logind and would also
  answer, but hypridle gets there first. Drop the `hyprlock` line from
  `hypridle.conf` if you want amane's.
- **The system tray is not covered.** amane has no StatusNotifier
  implementation at all — not an immature one, none. suzuha's `bar_tray`
  setting is three hardcoded notification/Wi-Fi/Bluetooth glyphs, not app
  icons. If you rely on tray icons, keep waybar enabled and treat amane's bar
  as experimental.

## Keeping the look

`settings` is symlinked to `~/.local/state/amane/settings`, and the shell
rewrites it in place, so the settings window edits this file directly. Diff
it after changing settings in the UI.

It pins `scheme=catppuccin` and `follow_wallpaper=false` so the palette
stays Catppuccin Mocha instead of being derived from the wallpaper, sets
`bar_height=36` (waybar ran 28px behind an 8px margin) and
`workspace_style=numbers` (waybar showed numbered workspaces). The accent
override is in `src/theme/scheme.rs` instead, because that is a compile-time
constant.

Weather, UV, humidity and air quality ship switched off; they need a place,
latitude and longitude under **Settings → Weather** first.

## Fonts

Four families, all required. Without Poppins the text-width heuristic in
`src/bar/pill.rs` mis-sizes every pill, since it is calibrated to Poppins
metrics. They are installed in `modules/nixos/fonts.nix`:

- Poppins
- JetBrainsMono Nerd Font
- Symbols Nerd Font
- Material Design Icons

## Theme integrations

All off by default. Each one, once enabled, writes config files for another
program:

| Setting | Writes |
| --- | --- |
| `integration_gtk` | `~/.local/share/themes/Amane{Light,Dark}/`, runs `dconf write`, replaces `~/.config/gtk-4.0/gtk.css` with a symlink, restarts `xdg-desktop-portal-gnome` |
| `integration_terminal` | kitty and foot colour files; also scans `/proc/*/environ` for `TERM=foot` and writes OSC sequences into those ttys |
| `integration_tmux` | `~/.local/state/amane/tmux-colors.conf` |
| `integration_vesktop` | rewrites the block between `/* amane-theme:start */` and `/* amane-theme:end */` in Vesktop's `quickCss.css` |
| `integration_spotify` | `~/.cache/amane/theme/spotify.css` |
| `integration_btop` | `~/.config/btop/themes/amane.theme` |
| `integration_cava` | `~/.config/cava/themes/amane` |

There is no ghostty integration, so the terminal palette stays whatever
`config/ghostty/linux-config` sets.

## Upstream

The shell is on hiatus until roughly mid-December 2026, so expect no fixes.
The unmodified upstream checkout sits in `../../suzuha`, and the library in
`../../amane`. To re-apply the three changes above after pulling upstream,
diff it against this directory:

```sh
diff -ru ../../suzuha/src src
```
